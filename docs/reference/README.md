# reference/

Information you look things up in — backend APIs, tool-call wire formats, benchmark scorecards.

**Put here:**
- vLLM / Ollama API quirks observed in practice.
- The `applyToolCallTransform` benchmark scorecard (when added).
- Wire-format references (Open AI tool-call shape, Ollama `<tool_call>` XML).

**Do not put here:**
- Runbook steps — `operations/`.
- Architecture overview — `architecture/`.
- Spike output — `research/`.

**Naming convention:** `<yyyy-mm-dd>-<topic>.md`
Examples: `2026-05-02-benchmarks.md`, `2026-08-01-ollama-tool-call-quirks.md`.

**Allowed `status:` values:** `Stable`, `Superseded`.

Date prefix is bumped when the doc is materially revised.
